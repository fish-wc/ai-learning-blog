# 基础能力

AI 工程岗位的基础能力包括编程、系统、数学和模型直觉。这里不追求把所有知识学完，而是优先建立能够支撑阅读源码、设计实验和排查问题的底座。

## 学习范围

- Python：类型、迭代器、异步、测试、性能分析和项目组织。
- Linux / Git：进程、网络、Shell、日志、分支协作和问题定位。
- 数据结构与算法：复杂度、哈希、树、图、搜索和常见面试题。
- 数学与统计：线性代数、概率、梯度、优化和实验中的统计直觉。
- 机器学习：数据划分、损失函数、正则化、优化、指标和误差分析。
- 深度学习：反向传播、归一化、注意力、训练稳定性和实验管理。

## 建议输出

每个主题都配一个最小实现和一个可复现实验，例如手写线性回归、实现简化版 Attention、比较不同优化器，或为一个 Python 模块补充测试。

后续笔记可以直接放在本目录下，文件名使用 `kebab-case`，只需写 Markdown 和一级标题即可自动进入侧边栏。
