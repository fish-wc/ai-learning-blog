# RAG

RAG（Retrieval-Augmented Generation）把外部知识接入语言模型。本目录沿着数据到答案的完整链路记录实践，而不是只记录某个向量数据库的 API。

## 学习范围

- 数据清洗、文档解析、切分策略和元数据设计。
- Embedding、稠密检索、稀疏检索与混合检索。
- 重排、上下文压缩、引用和答案生成。
- 离线数据集、召回率、准确率、Groundedness、延迟和成本。
- 增量更新、权限过滤、缓存和线上可观测性。

## 建议输出

先建立可重复的基线和小型评测集，再逐项替换切分、召回、重排和提示词策略；每次实验只改变一个主要变量。
