# CNCF
全称 Cloud Native Computing Foundation（云原生计算基金会），隶属于Linux基金会，负责托管、孵化云原生开源项目，项目分为沙盒、孵化、毕业三个阶段。Milvus、K8s、etcd均为CNCF毕业项目。

## 核心作用
1. 孵化、托管云原生开源项目，制定云原生相关理念标准；
2. 对项目做毕业分级：**沙盒(Sandbox) → 孵化(Incubating) → 毕业(Graduated)**，毕业代表项目成熟、生产可用。

> Milvus 是 CNCF 毕业项目；etcd、Kubernetes、Prometheus 也都是 CNCF 毕业项目。
