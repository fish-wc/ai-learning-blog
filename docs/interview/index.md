# 面试准备

面试准备与日常学习同步进行：每完成一个主题，就尝试用三分钟讲清楚；每完成一个项目，就整理设计取舍和故障复盘。

## 准备范围

- **基础知识**：Python、数据结构、机器学习、深度学习和概率统计。
- **LLM / Agent**：Transformer、微调、RAG、工具调用、评测和安全。
- **系统设计**：数据流、服务拆分、吞吐、延迟、容灾、成本和可观测性。
- **项目表达**：背景、职责、方案、实验、结果、失败和下一步。

## 每道题的记录方式

写出自己的答案后，再补充标准概念和反例；对于系统设计题，先画出最小可行架构，再逐步讨论规模扩大后的瓶颈。
