第 1 个子问题

对数求导策略：一条「回头看」的等式变形

它是 Policy Gradient 推导出 REINFORCE 的关键数学技巧。核心只有一步：把 ∇p 换一种写法。

1对 log p 求导
∇ log p = ∇p
p
链式法则的直接结果：对数的导数 = 自己分之一 × 自己的导数。
把分母 p 乘到另一边
2得到关键恒等式
∇p = p · ∇ log p
→
这一步为什么有用？
它把「概率 p 的导数 ∇p」重新写成了「p 乘上某个东西」。 一旦表达式里出现了 p · (…) 这种结构，就可以把它收进期望的定义里。
积分形式 → 期望形式
∫ ∇p dx = ∫ p·∇ log p dx = 𝔼x~p[ ∇ log p ]
💡
为什么要换成期望？
因为期望可以用 Monte Carlo 采样 近似求解——而积分很难直接算。
换成期望 → 就是为了能近似求解。
对数求导策略 / Log-derivative trick
上一章回顾

Policy Gradient：让「好轨迹」出现的概率更大

优化目标：环境给轨迹的奖励的期望最大。轨迹出现满足概率分布 pθ(τ)。

1优化目标
J(θ) = 𝔼τ~pθ(τ)[ R(τ) ]
让参数 θ 控制策略，使得「跑出来的轨迹 τ 收集到的回报 R(τ)」在期望上越大越好。
→
2展开成积分再求导
∇θJ(θ) = ∫ R(τ) ∇θ pθ(τ) dτ
期望 = 对概率密度积分。而 R(τ) 与环境有关、与 θ 无关，所以可以挪到求导符号外侧。
🎯
现在的处境：我们拿到了一个梯度表达式，但它还长着 ∫ … dτ 的样子——积分没法直接算，也没法采样。 下一页，就用「对数求导策略」把 ∇θpθ(τ) 换掉。

第 2 个子问题

REINFORCE 的推导：一步替换，积分变期望

把上一页的 ∇θpθ 用对数求导策略换掉，REINFORCE 就浮现出来了。

① 代入对数求导恒等式
∇θpθ(x) = pθ(x) · ∇θ log pθ(x)
② 梯度表达式等效变形 —— 出现 pθ(τ) 因子
∇θJ(θ) = ∫ R(τ) pθ(τ) ∇θ log pθ(τ) dτ
③ 认出期望的定义，积分写成期望
∇θJ(θ) = 𝔼τ~pθ[ R(τ) ∇θ log pθ(τ) ]
和原来比，变了什么？
原来：∫ R(τ)∇p dτ —— 对概率求导，积分不可采样
现在：𝔼[R(τ)∇log p] —— 对对数概率求导，期望可采样
关键洞察
式子里每一项都变成可观测的了：
R(τ) = 跑一遍就知道奖励；∇log pθ = 网络自己就能求导。

第 3 个子问题

理解 REINFORCE：用「跑 100 条轨迹」估出梯度

得到期望形式后，就可以用 Monte Carlo 采样 求梯度的近似值——这就是全部秘密。

①用当前策略跑 100 条轨迹
τ₁ τ₂ τ₃ ⋯ τ₁₀₀
每条轨迹都带回环境给的奖励 R(τi)。
关键：τ 被采样结果固定下来后， pθ(τi) 就只是关于 θ 的函数 → 可以正常求导。
→
②取平均，作为真实梯度的估计
ĝ = 1
100 Σi=1100 R(τi) ∇θ log pθ(τi)
用这个式子来近似求解真实梯度，再拿它去做梯度上升更新策略。
🧠
REINFORCE 本质上就是 Monte Carlo Policy Gradient
策略梯度 + 蒙特卡洛采样估计 = REINFORCE。没有别的魔法。

附加知识点 · 预告
预备：化简梯度

把 ∇ log pθ(τ) 拆开：只剩策略项

轨迹概率由「初始状态 × 各步策略 × 各步状态转移」累乘而成。取对数，累乘变累加。

① 轨迹的概率（累乘）
pθ(τ) = ρ₀(s₀) ∏t πθ(at|st) P(st+1|st,at)
蓝 = 策略（与 θ 有关）　灰 = 环境（与 θ 无关）
→
② 取对数（累乘变累加）
log pθ(τ) = log ρ₀(s₀) + Σt log πθ(at|st) + Σt log P(st+1|st,at)
对 θ 求导时，灰色项全是常数 → 导数为 0。
③ 求导后：环境与初始状态项全部消失
∇θ log pθ(τ) = Σt ∇θ log πθ(at|st)
带回目标梯度： ∇θJ(θ) = 𝔼τ~pθ[ R(τ) Σt∇θlog πθ(at|st) ]
✅
环境动态（状态转移）不含 θ，所以求导后消失。梯度里只剩下策略自己的对数概率——这是一个巨大的简化，也是后续两个知识点的基础。
化简 · 只留策略项
附加问题 01

为什么用 Return-to-Go 更新策略？

一个动作该得多少奖励，应该看它当下 + 之后的影响，而不是整条轨迹一把抓。

⚠️ 问题：每个动作分到的是同一个 R(τ)
R(τ) Σt∇log π(at|st) 对每个 action 都乘以整条轨迹的奖励 R(τ)。
也就是说 → 动作 a₁ 和 a₉ 拿到的奖励一模一样，明显不合理。
解度量单个动作的奖励：Return-to-Go
一个动作的奖励 = 当前立刻得到的 r + 它对未来的影响。用衰减因子 γ 粗略累计：
Gt = Σk=tT−1 γk−t rk
γ 越靠后越小 → 越远的未来影响越弱。
替换结果
原来
R(τ)∇logπ
→
现在
Gt∇logπ
∇θJ ≈ Σt Gt ∇θlog πθ(at|st)
后面统一用 Gt 表示当前动作 at 的奖励。
Return-to-Go · 未来回报
问题浮现

当前梯度表达式的问题：动作之间差异变小，方差大

状态本身就好时，所有动作的回报都高，动作之间的「高低」被淹没了。

1动作差异被缩小
同一状态 st 下三个动作的收益：
99
100
101
收益都很高，但相对差异被压缩 → 梯度更新时，没法有效增益更好的动作。
2方差被放大
梯度里还乘了一项 ∇θlog π，于是：
Var(X) = 𝔼[(X − 𝔼[X])²]
Var[c·X] = c² Var[X]
📉
系数 c 越大，方差按平方放大。所以——降低系数 Gt，就能降低方差。
同一组数，减去一个常数 → 差异不变
99 / 100 / 101 → 减 100 → −1 / 0 / +1
但真实梯度里还乘了 ∇log π，数值被拉大，方差随之放大。
方差分析 · 为什么需要 baseline
附加问题 02

解决方案：在奖励 Gt 上减去一个 baseline

把「绝对收益」换成「相对于平均水平的收益」——这就是优势（Advantage）思想的雏形。

做法：Gt → Gt − b(st)
∇θJ ≈ Σt ( Gt − b(st) ) ∇θlog πθ(at|st)
b(st) 通常取 Vπ(st)——当前状态 st 下采取动作的综合收益期望（即「这个状态的平均水平」）。
💡
理解：动作的收益 Gt 减去当前状态的平均收益 Vπ(st)。
增益更大的动作 → 得到相对更多的梯度更新 → 概率被抬高。
效果对比：同一状态下
动作Gt−Vπ=100
a₁99−1
a₂1000
a₃101+1
减之前：99/100/101 看不出差别
减之后：−1 / 0 / +1 —— 谁好谁坏一目了然
好处 1：相对差异被放大，更新方向更清晰
好处 2：系数变小 → 梯度方差显著降低
好处 3：期望不变，方向没被改坏（见下页）
Baseline · 优势思想
附加问题 03

为什么减 baseline，梯度的期望不变？

因为含 b(s) 的那一项，期望恒等于 0。下面是一步步的证明。

① 目标：证明含 b(s) 的期望为 0
𝔼[ b(s) · ∇θlog πθ(a|s) ] = 0
② 关键：baseline 不依赖采样出的 action
= b(s) Σa πθ(a|s) ∇θlog πθ(a|s)
b(s) 与 a 无关，可以提到求和符号外面。
③ 用对数求导策略反向替换
= b(s) Σa ∇θ πθ(a|s)
④ 梯度移到求和符号外
= b(s) ∇θ Σa πθ(a|s)
⑤ 概率之和恒为 1，常数的导数为 0
Σa πθ(a|s) = 1　⟹　∇θ(1) = 0
每一步在干什么
步骤动作
②展开期望 → b(s) 提出
③∇log π 换回 ∇π
④求导符号外移
⑤概率和为 1 → 导数为 0
得证
𝔼[ b(s) ∇θlog πθ(a|s) ] = 0
减去 baseline 不改变梯度的期望方向，只降低方差 → 免费的性能提升。
证明 · 期望不变性
总结

一句话回顾这一章

1对数求导策略是什么？
一条等式变换 ∇log p = ∇p / p。它把概率分布 p 重新引入梯度表达式，从而实现积分形式与期望形式的等效变换——这样才能用 Monte Carlo 采样近似求梯度。
2REINFORCE 怎么推出来的？
使用对数求导策略，把 Policy Gradient 的梯度积分表达式，转换为期望表达式即可。
3REINFORCE 到底是什么？
本质上就是 Monte Carlo Policy Gradient。策略梯度 + 蒙特卡洛采样估计。
三个补充知识点
① 为什么用 Return-to-Go？
原始公式用整条轨迹的奖励奖励每一次动作，但每个动作应得的奖励不同。一个动作的奖励体现在当前及之后，所以用未来回报 Gt 来度量。
② 为什么要减 baseline？
同一状态下动作收益基数大，动作间差异体现不出来。减去基数（通常取 Vπ(st)）能扩大相对差异；且因额外乘了 ∇log π，减完后方差变小。
③ 为什么期望不变？
因为 b(st) 与动作 at 无关，可证明 b(s)Σa∇θπθ(a|s) 的期望为 0。
