# FSDP 是什么
**FSDP = Fully Sharded Data Parallel，全分片数据并行**，是 PyTorch 官方推出的**大模型分布式训练**工具（PyTorch FSDP）。
> 一句话概括：把模型参数、梯度、优化器状态**分片（sharding）**放到多张GPU上，而不是每张GPU都存完整模型，从而训练超大模型，解决单卡显存不够的问题。

## 对比理解（和 DDP 的区别）
- **DDP（Data Parallel，数据并行）**：每张GPU都保存一份**完整模型**；只把训练数据切分到不同GPU。
  缺点：模型大了，单卡存不下完整模型。比如70B大模型，单张卡放不下完整权重，DDP直接不能用。
- **FSDP**：把模型权重、梯度、优化器状态**拆开分片**，不同GPU只存一部分；前向/反向传播时按需通信收集需要的参数。
  ✅ 优点：**显存占用大幅降低**，可以在多卡上训练超大模型（LLaMA、Qwen这类大模型训练常用）

## FSDP 的分片策略（sharding strategy）
1. `FULL_SHARD`（默认）：参数、梯度、优化器状态全部分片，显存最省，通信开销最大
2. `SHARD_GRAD_OP`：只分片梯度+优化器，参数保留完整，显存中等，通信更少
3. `NO_SHARD`：不分片，等价DDP，一般测试用
4. `HYBRID_SHARD`：混合分片，多机场景，单机内部分片，机器之间数据并行

## 简单工作流程
1. 模型被切分成多个分片，分配给不同GPU；每个GPU只持有一部分参数
2. 前向传播：计算某一层时，**临时收集**该层全部参数到当前GPU，计算完成立刻释放
3. 反向传播同理：需要梯度的时候收集参数，算完梯度再分片释放
4. 优化器更新：每个GPU只更新自己负责的那部分参数分片

## 极简代码示例（PyTorch FSDP）
```python
import torch
from torch.distributed.fsdp import FullyShardedDataParallel as FSDP

# model 是你的大模型
model = FSDP(model)
```
> 实际使用还要：初始化分布式进程组、配置分片策略、wrap模型层、设置自动包装等，这只是核心一行。

## 适用场景
✅ 训练大语言模型、大视觉模型，**模型太大单卡放不下**
✅ 多GPU、多机分布式训练

❌ 小模型没必要用FSDP，DDP足够；FSDP会带来通信开销，小模型反而变慢

## 一句话总结
DDP：每卡一份完整模型；
FSDP：模型拆碎分给多张卡，按需拼装计算，**牺牲一点通信速度换巨大显存节省，专门用来训超大模型**。
