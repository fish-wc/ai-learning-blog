## 三个最重要的观念（先记住再往下读）

1. **口径先于数字**。评测分析 80% 的事故出在口径：分母用谁、失败算不算 0 分、两侧是不是同一把尺。任何数字出口前先问"这是什么口径"。
2. **证据分级，不做无证据归因**。有轨迹（T）说 T 级的话，只有判词（J）就说 J 级的话；"不确定"写"未决"比硬给结论专业得多。
3. **读者视角倒推产出**。报告和明细表是给"要安排下一步动作的人"看的：打开就能懂、能追溯到具体 case、知道该改什么——达不到这个标准就是没做完。
