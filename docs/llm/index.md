# 大模型

本目录记录从模型原理到训练、微调、推理和评测的学习过程，重点关注公式背后的计算、实现中的工程取舍，以及如何用实验验证理解。

## 学习范围

1. Tokenization、Embedding、位置编码与 Attention。
2. Transformer 结构、训练目标、优化和规模化规律。
3. 预训练数据、监督微调、参数高效微调与对齐。
4. KV Cache、批处理、量化和长上下文推理。
5. 能力评测、幻觉分析、成本/延迟与安全边界。

## 建议输出

每篇笔记尽量包含一个小实验：给出环境、输入、指标和结论。对于模型对比，先固定数据和评测方法，再讨论结果。
